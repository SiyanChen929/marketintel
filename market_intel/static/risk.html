    Methodology & lineage
    Each construction is computed independently and reported in three layers: model = fully-invested target weights; common-vol-target scenario = the same book recalculated here against its own ex-ante volatility (a hypothetical, not a book any run executed); actual landed run book = the weights the run really published, read from run.json and available only for the run's own executable column. A window a book cannot support is reported unavailable with the limiting holding named — never shortened, never zero. data_snapshot_hash identifies the shared market data and is identical across constructions; portfolio_weights_hash is what differs. No route is published as preferred.
